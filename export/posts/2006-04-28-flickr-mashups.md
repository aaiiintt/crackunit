I’m pretty sure I’m way behind the curve on these (as per usual). But here’s a couple of amazing uses of the Flickr API (if you don’t know what an API is, [this might help](http://en.wikipedia.org/wiki/Application_programming_interface). Or then again, it might leave you baffled).

[![tagnautica](/wp-content/uploads/2006/04/Picture%204.thumbnail.jpg)](/wp-content/uploads/2006/04/Picture%204.jpg "tagnautica")[Tagnautica](http://www.quasimondo.com/tagnautica.php) – A really lovely way of navigating related tags in ‘FlickrSpace’. It’s just one of those interfaces that is so simple and just really really nice to use. You just need one search to start to explore the world of photo tags. Love it.

[![flapr](/wp-content/uploads/2006/04/Picture%205.thumbnail.jpg)](/wp-content/uploads/2006/04/Picture%205.jpg "flapr")[Flapr](http://www.bcdef.org/flappr/) – A flash based interface for Flickr. Don’t get me wrong. I really like the normal Flickr interface, I think it’s great. But these guys have done a really nice flash alternative. It feels snappy and responsive, and just, well…different. Try it, you might like it.

[![FlickrFling](/wp-content/uploads/2006/04/Picture%203.thumbnail.jpg)](/wp-content/uploads/2006/04/Picture%203.jpg "FlickrFling")[FlickrFling](http://www.nastypixel.com/prototype/cms/myfiles/pages/flickrfling/) – An online application that converts an RSS feed into images pulled from Flickr. I can’t really see the use for it, but once I started playing with it I was strangely compelled. [Read more about it.](http://www.nastypixel.com/prototype/cms/wordpress/?page_id=78)

Taken from [Wired’s Top 10 Flickr Mashups](http://www.webmonkey.com/webmonkey/06/08/index4a_page2.html?tw=commentary) – there’s a few other sweet ones in there, but these three were new to me.
